# Koi-Maestro benchmark journal

Every accepted intervention, its verification gate, and its paired benchmark
delta. Manifests live in `docs/benchmarks/manifests/`; reports live under
`docs/benchmarks/` by phase. Evidence produced by dirty-tree builds carries
`verdict: "development"` in its report — informational only, never
canonical.

## Baseline inventory

- P0 core commit: tag `engine-v0.1-p0-core` (Windows host gate green
  2026-09-19: fmt / clippy `-D warnings` / nextest 64-64 `release-ci` /
  doctests / aarch64 + x86_64-linux cross-checks).
- Gate status at baseline: fmt / clippy / nextest / doctests / cross —
  defined in `scripts/check.{ps1,sh}`.

## Benchmark protocol

- Unit of inference = **deal cluster** (mirrored legs on the same deal,
  dealer swapped — the Koi-Koi seat asymmetry).
- Cluster bootstrap CI ≥ 0.99, ChaCha8-seeded deterministic resampling.
- Forfeit policy: intention-to-treat — `invalid`/`time_forfeit` legs score
  as losses and are reported separately from valid legs.
- Provenance: every artifact carries the `koi-build-info` identity
  (commit/tree/dirty + source digest + lockfile + toolchain + rustflags/PGO).
- Stopping: manifest-declared (fixed clusters / GSPRT with calibrated α/β /
  EB-CS equivalence); cap-before-min-clusters → LLR `null`, never fabricated.
- Profile: canonical numbers come from `--profile release` binaries only.
